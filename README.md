## Instructions 
Les scripts fournis ont pour objectif de vous donner une idée des étapes à suivre (fine-tuning, inférence, RAG, évaluation).

Ils ne sont pas garantis comme directement fonctionnels dans votre environnement.

Il vous appartient de :

- Débuguer si nécessaire

- Adapter le code à votre configuration

- Ajuster les hyperparamètres

- Améliorer la structure expérimentale

Vous êtes également encouragés à proposer des variantes méthodologiques si elles sont justifiées, par exemple :

- Utiliser QLoRA au lieu de LoRA

- Implémenter un GraphRAG

- Tester d’autres stratégies de retrieval ou de chunking

La capacité à adapter, améliorer et justifier vos choix techniques fait partie des critères d’évaluation.
